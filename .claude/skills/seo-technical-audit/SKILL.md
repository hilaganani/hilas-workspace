# seo-technical-audit — ביקורת SEO טכנית

## מטרה והיקף

ביקורת טכנית של אתר שלם (לא מאמר בודד — זה `seo-on-page-audit`), מבוססת על `WebFetch` לקבצים/דפים ציבוריים (`robots.txt`, `sitemap.xml`, HTML של דפים מדגמיים) — **לא** crawler אמיתי שסורק את כל האתר. לכן הביקורת היא מדגמית (דוגמת עמודים, לא כל עמוד באתר) ויש לתייג זאת בפלט.

**Core Web Vitals תלוי במפתח API אופציונלי** (`PAGESPEED_API_KEY`, חינמי מ-Google Cloud Console) שלא בהכרח מוגדר בפרויקט. **אם המפתח לא קיים ב-`.env` — דלג על סעיף ה-CWV, ציין זאת בבירור בפלט ("Core Web Vitals לא נבדק — נדרש PAGESPEED_API_KEY שלא מוגדר"), ואל תמשיך עם שאר הביקורת כאילו לא קרה כלום.** זו לא חסימה לשאר הביקורת, רק לסעיף הזה.

## מתי להשתמש

- בקשה מפורשת לאודיט טכני / "בדיקת בריאות SEO טכנית" לאתר.
- חשד לבעיית אינדוקס (עמודים לא מופיעים בגוגל) או ביצועים.

## קלט נדרש

| שדה | חובה/רשות |
|---|---|
| root URL של האתר (למשל `https://example.com`) | חובה — **תמיד מועבר כפרמטר בזמן הפעלה**, אין דומיין קבוע מוגדר מראש בפרויקט |
| דגימת עמודים לבדיקה מעמיקה (3-8 URL-ים) | רשות — אם לא סופקו, נבחרים מתוך ה-sitemap |
| `PAGESPEED_API_KEY` ב-`.env` | רשות — נדרש רק לסעיף Core Web Vitals |

## תהליך עבודה

הרשימה המלאה של כל 13 הבדיקות, כולל **איך** לבצע כל אחת בפועל (אילו קבצים לקרוא, מה מהווה "בעיה", ודוגמאות), נמצאת ב-[references/checklist.md](references/checklist.md) — קובץ ארוך יחסית, נקרא ישירות מ-SKILL.md כדי לשמור עליו מחוץ להקשר עד שצריך אותו.

**זרימת העבודה ברמה הגבוהה**:

1. `WebFetch` על `<root>/robots.txt` — בדוק שאין חסימה לא-מכוונת של דפים חשובים.
2. `WebFetch` על `<root>/sitemap.xml` (או `sitemap_index.xml`) — זו רשימת בסיס לדגימת עמודים ולבדיקת פערים.
3. עבור על checklist.md סעיף-סעיף, לפי הדגימה שנקבעה.
4. אם `PAGESPEED_API_KEY` קיים — הרץ Core Web Vitals לפי המתכון ב-checklist.md.
5. תעדף את כל הממצאים לפי **חומרה** (severity), **השפעה** (impact), ו**קושי יישום** — ראה טבלת פלט למטה.

## ולידציה ומקרי קצה

- **`robots.txt` לא קיים** (404) — זה תקין טכנית (ברירת מחדל: הכל מותר לסריקה), לא באג — ציין זאת ואל תדווח כ"בעיה".
- **`sitemap.xml` לא נגיש** — נסה `sitemap_index.xml`, ואם גם זה נכשל, דווח שהביקורת מוגבלת לדפים שסופקו ידנית בלבד (אם סופקו) או שלא ניתן היה למפות את האתר.
- **`PAGESPEED_API_KEY` חסר** — דלג על CWV בלבד, כמתואר למעלה. אל תמציא ציוני ביצועים.
- **אתר עם Basic Auth / חסימת בוטים** — `WebFetch` עלול להיכשל על כל הדף; דווח זאת ואל תמשיך עם ניחוש.
- **hreflang רלוונטי רק לאתרים רב-לשוניים** — אם האתר בעברית בלבד ואין גרסאות שפה נוספות, ציין "לא רלוונטי" ולא "בעיה חסרה".
