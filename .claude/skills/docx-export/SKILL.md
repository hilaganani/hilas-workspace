# docx-export — המרת Markdown עברי ל-Word (.docx)

## מה זה עושה

סקריפט פייתון (`scripts/md_to_docx.py`) שקורא קובץ `.md` וכותב קובץ `.docx` תואם, עם תמיכה מלאה בעברית/RTL:

- כותרות `#`/`##`/`###` → סגנונות Heading של Word.
- `**מודגש**` ו-`` `קוד` `` → הדגשה/גופן monospace בתוך הטקסט.
- רשימות `- `/`* `/`1. ` → רשימות Word אמיתיות (Bullet/Number).
- ציטוטים `> ` → פסקה עם הזחה.
- טבלאות Markdown (`| ... |`) → טבלאות Word אמיתיות (`Table Grid`), לא טקסט מיושר.
- **כל** הפסקאות, הרצים, והטבלאות מקבלות `w:bidi`/`w:rtl`/`w:bidiVisual` ומיושרות לימין — הקובץ ייפתח נכון ב-Word כמסמך עברי מימין-לשמאל, לא כטקסט אנגלי הפוך.

## שימוש

```bash
python3 .claude/skills/docx-export/scripts/md_to_docx.py <input.md> <output.docx>
```

לדוגמה, כדי לייצא תוכנית תוכן של יעל:

```bash
python3 .claude/skills/docx-export/scripts/md_to_docx.py yael/outputs/2026-07-content-plan.md yael/outputs/2026-07-content-plan.docx
```

## דרישות מקדימות

חבילת פייתון `python-docx`:

```bash
python3 -c "import docx" 2>/dev/null || pip3 install python-docx
```

**לא** דורש Node/npm — זו החלטה מכוונת, כי לא תמיד יש Node מותקן בסביבת ההרצה (בניגוד לדוגמאות ברירת המחדל של סקילי docx שמניחות `docx` דרך npm). אם יש בעתיד גישה אמינה ל-Node, `docx` (npm) יכול לספק תוצאה עשירה יותר (עיצוב מתקדם, TOC וכו') — אך הסקריפט הנוכחי מספיק לצורך תוכניות תוכן/מסמכים טקסטואליים עם טבלאות.

## מגבלות ידועות

- אין תמיכה בתמונות מוטמעות, היפר-קישורים לחיצים, או Table of Contents אוטומטי — לצרכים האלה יש להשתמש בסקיל `docx` הכללי (`anthropic-skills:docx`, מבוסס Node) אם Node זמין.
- טבלאות בעברית עם עמודות ברוחב לא-אחיד לא מותאמות אוטומטית לרוחב תוכן — Word יחלק את הרוחב באופן שווה בין העמודות; זה קריא אך לא תמיד אופטימלי ויזואלית לטבלאות עם עמודה אחת ארוכה במיוחד.
- לפני מסירת קובץ כמוגמר — מומלץ לבדוק מבנית (לא רק להניח שהומר נכון): לספור פסקאות/טבלאות בקובץ הפלט ולוודא שהם תואמים למקור (ראו קוד הבדיקה בהיסטוריית הפרויקט אם צריך דוגמה), ואם יש `soffice` (LibreOffice) זמין בסביבה — להמיר ל-PDF ולבדוק ויזואלית לפי התהליך המתואר בסקיל `anthropic-skills:docx`.
