# email-send — שליחת מייל דרך Resend

## עקרון מפתח: שליחה בלבד, חד-כיוונית

הסקיל הזה **שולח מייל בלבד**. אין בו יכולת לקרוא תיבת דואר נכנס, לזהות תשובות, או "להקשיב" לאישור שחוזר במייל. אישור המשתמשת חוזר תמיד בצ'אט (בשיחה הבאה עם רועי) — לא במייל עצמו. אם בעתיד יידרש ניתוח תשובות מייל, זו הרחבה נפרדת ומכוונת, לא הרחבה שקטה של הסקיל הזה.

## דרישות מקדימות

ב-`.env` בשורש הפרויקט:
- `RESEND_API_KEY` — מפתח API מ-[resend.com](https://resend.com/api-keys) (יש שכבה חינמית, לא דורש כרטיס אשראי להתחלה).
- `PLAN_EMAIL_TO` — כתובת המייל של המשתמשת לשליחת התוכנית השבועית.

**אין צורך באימות דומיין לפני שימוש ראשוני:** Resend מספק כתובת שולח מוכנה מראש — `onboarding@resend.dev` — שעובדת מיד, בלי הגדרות DNS. זה מתאים להתחלה. אם רוצים לשלוח מכתובת מותאמת אישית (למשל `roi@ganani.co.il`), צריך לאמת את הדומיין ב-Resend קודם (רשומות DNS) ואז לעדכן את כתובת השולח בקריאה.

## הקריאה הבסיסית

```bash
curl -s -X POST "https://api.resend.com/emails" \
  -H "Authorization: Bearer $RESEND_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "from": "רועי <onboarding@resend.dev>",
    "to": ["'"$PLAN_EMAIL_TO"'"],
    "subject": "<כותרת המייל>",
    "html": "<תוכן המייל, HTML פשוט, RTL>"
  }'
```

## תבנית HTML מומלצת (עברית, RTL)

```html
<div dir="rtl" style="font-family: Arial, sans-serif; text-align: right;">
  <h2>התוכן כותרת כאן</h2>
  <p>פסקת פתיחה...</p>
  <table dir="rtl" style="width:100%; border-collapse: collapse;">
    <tr><th style="border:1px solid #ddd; padding:8px;">עמודה</th></tr>
    <tr><td style="border:1px solid #ddd; padding:8px;">תוכן</td></tr>
  </table>
</div>
```

## טיפול בשגיאות

- **`401`** — `RESEND_API_KEY` שגוי/פג תוקף.
- **`403` עם הודעה על דומיין** — ניסיון לשלוח מכתובת שולח לא מאומתת (לא `onboarding@resend.dev` ולא דומיין מאומת בחשבון) — חזרו ל-`onboarding@resend.dev` או אמתו את הדומיין קודם.
- **תגובת JSON בלי שדה `id`** — סימן לשגיאת שליחה; הדפיסו את כל גוף התגובה כדי לאבחן במקום להניח הצלחה.
- **תמיד** ודאו קוד תגובה `200`/`201` ושדה `id` בתגובה לפני שמדווחים שהמייל נשלח בהצלחה — אל תניחו הצלחה רק כי ה-curl לא זרק שגיאת רשת.
