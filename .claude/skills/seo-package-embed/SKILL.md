# seo-package-embed — חבילת ה-SEO בתוך המאמר עצמו

## מטרה והיקף

עד היום חבילת ה-SEO של דני נשמרה **רק** כקובץ נפרד ב-`dani/outputs/<name>-seo.md`, כך שבזמן הפרסום בוורדפרס היה צריך לפתוח שני קבצים במקביל - את המאמר ואת ההוראות. הסקיל הזה משבץ את **חבילת הפרסום בלבד** בתחתית קובץ ה-`.html` של המאמר, אחרי `</main>`, כבלוק מעוצב ומסומן.

הקובץ הנפרד ב-`dani/outputs/` **נשאר כפי שהוא** - הסקיל לא מוחק ולא משנה אותו. הוא מקור האמת המלא (כולל אודיט וקריאות); הבלוק המשובץ הוא נוחות בזמן הפרסום.

## מה משובץ ומה לא

**משובץ**: סעיף חבילת הפרסום בלבד - כותרת SEO, מטא תיאור, slug, מילות מפתח בפועל, הצעות alt-text.

**לא משובץ** (נשאר רק ב-`dani/outputs/<name>-seo.md`): אימות הקישורים הפנימיים, מספרי הקריאות מהסקריפט, והערות השיפור הלא-חוסמות. אלה תיעוד QA של תהליך העבודה של דני, לא משהו שמעתיקים לתוסף ה-SEO בזמן פרסום.

הסקריפט מזהה את הסעיף לפי כותרת שמכילה אחת מהוריאציות: `חבילת SEO סופית` / `חבילת SEO לפרסום` / `חבילת מטא-דאטה`, ולוקח ממנה עד הכותרת הבאה באותה רמה. אם הכותרת היחידה שמתאימה היא **כותרת המסמך** (בראש הקובץ) - מדלג עליה ומחפש התאמה פנימית, כי כותרת המסמך בקבצים היסטוריים נקראת גם היא "חבילת SEO לפרסום: <שם המאמר>".

## פקודה

```bash
python3 ${CLAUDE_SKILL_DIR}/scripts/embed_seo.py \
  --html output/<name>.html \
  --seo dani/outputs/<name>-seo.md
```

מחזיר JSON עם `action`: `inserted` (בלוק חדש), `replaced` (היה בלוק קודם - הוחלף), או `appended` (לא נמצא `</body>`).

## הבלוק המשובץ

- ממוקם **אחרי** `</main>` ולפני `</body>` - כלומר מחוץ לגוף המאמר.
- עטוף בהערות HTML: `<!-- SEO-PACKAGE-START ... -->` ו-`<!-- SEO-PACKAGE-END -->` - כדי שיהיה קל להסיר ידנית, וכדי שהרצה חוזרת תחליף אותו במקום לשכפל.
- פותח בקו מקווקו ובאזהרה בולטת: "לשימוש פנימי בזמן הפרסום בלבד. אין להעתיק את החלק הזה לגוף המאמר באתר."
- מעוצב בצבעי המותג (`brand/tokens.json` / `merav/brand-guidelines.md`), RTL, כולל טבלאות ו-`<code>` ל-slug.

## ולידציה ומקרי קצה

- **לא נמצא סעיף חבילת פרסום ב-`-seo.md`** - הסקריפט **נכשל במפורש** (exit 1) ולא משבץ כלום, במקום לשבץ בשוגג את כל קובץ ה-QA. במקרה כזה יש לוודא שדני שמר את החבילה תחת כותרת בפורמט המחייב (ראו `.claude/agents/dani.md`).
- **הרצה חוזרת** - מחליפה את הבלוק הקיים. בטוח להריץ שוב אחרי שדני עדכן את חבילת ה-SEO.
- **פורמט לא עקבי בקבצים היסטוריים** - שלושת קובצי ה-`-seo.md` שנכתבו לפני 2026-07-27 השתמשו בשלושה ניסוחי כותרת שונים לאותו סעיף. כולם נתמכים, אבל הפורמט המחייב מכאן ואילך מתועד ב-`dani.md` כדי שהזיהוי לא יישבר.
- **תמונות בנתיב יחסי** - הסקיל לא נוגע בהן. אם המאמר מיועד לשליחה כמייל (לא רלוונטי למאמרי בלוג), ראו את ההערה על נתיבים מוחלטים ב-`noga/style-guide.md` סעיף 9.11.

## שילוב עם Drive

מאחר ש-Google Drive לא מרנדר HTML (מציג קוד גולמי), אחרי השיבוץ כדאי להריץ גם את `html-to-pdf` ולהעלות את שני הקבצים - ה-`.html` (לעריכה/העתקה) וה-`.pdf` (לצפייה מהירה בדרייב) - דרך `drive-upload`, לתיקיית `dani-outputs` בדרייב.
